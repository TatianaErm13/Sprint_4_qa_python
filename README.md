Тестирование класса BooksCollector
Этот документ рассказывает о тестах для класса BooksCollector. Этот класс помогает управлять коллекцией книг — добавлять их, указывать жанры и отмечать любимые книги.


Какие тесты мы сделали
Тест test_add_new_book

Что проверяем: правильно ли добавляются книги с разными названиями.

Как проверяем:

пытаемся добавить книгу с нормальным названием — она должна добавиться;

пробуем добавить книгу с пустым названием (ничего не пишем) — она не должна добавиться;

пробуем добавить книгу с очень длинным названием (больше 40 символов) — она тоже не должна добавиться.

Какой метод тестируем: add_new_book(name).

Тест test_set_book_genre

Что проверяем: можно ли правильно указать жанр для книги.

Как проверяем:

указываем существующий жанр — он должен установиться;

пробуем указать какой‑то странный, несуществующий жанр — он не должен установиться (жанр останется пустым).

Какой метод тестируем: set_book_genre(name, genre).

Тест test_get_book_genre_existing_book

Что проверяем: умеет ли программа показать жанр у книги, которая есть в коллекции.

Как проверяем: добавляем книгу и указываем для неё жанр. Потом спрашиваем у программы этот жанр — она должна его правильно показать.

Какой метод тестируем: get_book_genre(name).

Тест test_get_books_with_specific_genre

Что проверяем: может ли программа найти все книги определённого жанра.

Как проверяем:

ищем книги в жанре, где они есть, — программа должна показать список;

ищем книги в пустом жанре — программа должна сказать, что книг нет (вернуть пустой список).

Какой метод тестируем: get_books_with_specific_genre(genre).

Тест test_get_books_genre_returns_dict

Что проверяем: возвращает ли метод словарь со всеми книгами и их жанрами.

Как проверяем: просто запускаем метод после создания объекта — он должен вернуть словарь (может быть пустым).

Какой метод тестируем: get_books_genre().

Тест test_get_books_for_children_age_rating_exclusion

Что проверяем: не попадают ли «взрослые» книги (например, ужасы или детективы) в список детских.

Как проверяем:

добавляем книги разных жанров, в том числе «взрослых»;

просим показать книги для детей — в списке должны быть только подходящие (мультфильмы, комедии и т. д.), а «взрослые» книги — отсутствовать.

Какой метод тестируем: get_books_for_children().

Тест test_add_book_in_favorites

Что проверяем: правильно ли книги добавляются в избранное.

Как проверяем:

добавляем существующую книгу — она должна появиться в избранном;

пробуем добавить несуществующую книгу — она не должна попасть в избранное.

Какой метод тестируем: add_book_in_favorites(name).

Тест test_delete_book_from_favorites_success

Что проверяем: можем ли мы убрать книгу из избранного.

Как проверяем: сначала добавляем книгу в избранное, потом удаляем её. После этого проверяем — книги не должно быть в списке избранного.

Какой метод тестируем: delete_book_from_favorites(name).

Тест test_get_list_of_favorites_books_empty_initially

Что проверяем: пуст ли список избранного сразу после создания коллекции.

Как проверяем: создаём новый объект BooksCollector и сразу спрашиваем список избранного — он должен быть пустым.

Какой метод тестируем: get_list_of_favorites_books().

Тест test_get_list_of_favorites_books_after_adding

Что проверяем: появляется ли книга в избранном после добавления.

Как проверяем: добавляем книгу в избранное и спрашиваем список — в нём должна быть наша книга.

Какой метод тестируем: get_list_of_favorites_books().

Что ещё нужно знать
Инструмент для тестов: мы использовали pytest — это специальная программа для проверки кода.

Как упростили тесты: в некоторых тестах мы использовали «параметризацию» — это значит, что один и тот же тест запускается несколько раз с разными данными. Так мы не повторяем код и проверяем сразу много вариантов.

Что покрыто тестами: каждый основной метод класса BooksCollector проверен хотя бы одним тестом.

Как запустить тесты
Сначала убедитесь, что у вас установлен pytest. Если нет, установите его командой:

bash
pip install pytest
Положите файлы в одну папку:

main.py — тут находится класс BooksCollector;

test_books_collector.py — тут лежат наши тесты;

README.md — этот файл с описанием.

Откройте терминал в этой папке и запустите тесты:

bash
pytest -v test_books_collector.py
Флаг -v делает вывод подробным — вы увидите названия всех тестов и их результат (PASSED или FAILED).
